# Write: an agent skill for writing and speaking like a human

![A blue fountain pen nib pulls tangled gray strips into clean blue lines](/.github/images/cover.webp)

This is the installable English version of the Russian `napishi` skill. It helps Claude, ChatGPT, and Codex write clear prose, edit without flattening the author's voice, remove clusters of AI-writing patterns, and handle difficult conversations with warmth and backbone.

> Repository information and installation options are in the [root README](../../README.md).

## Use it for

- emails, messages, posts, articles, landing pages, newsletters, reports, and documentation;
- editing for clarity, rhythm, concrete detail, and natural English;
- removing corporate jargon, clichés, filler, and synthetic-sounding prose;
- stories, premises, scenes, endings, and writer's block;
- disagreement, negotiation, bad news, boundaries, feedback, praise, and criticism.

The skill is for prose and human conversation, not code generation.

## Examples

**Draft:**

> Write an email telling a client that the project will be three days late.

**Edit:**

> Rewrite this so it sounds like a thoughtful person, not a press release: [text]

**Review:**

> Show me where this article sounds machine-written without rewriting it.

**Conversation:**

> Help me tell my manager I disagree with this plan without turning it into a fight.
